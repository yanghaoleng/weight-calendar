# 体重日历

一个面向手机使用的按日体重记录 Web App。用户只需设置一个唯一的四位或六位数字密码，不需要手机号或邮箱。

## 功能

- 打开网站直接进入可操作的 Demo 月历，底部按钮用于打开个人体重日历。
- 密码默认使用四位，也可在键盘标题旁切换为六位；输满后自动识别已有账户或新密码。
- 新密码会先询问是否创建账户，可选填昵称，再重复密码确认。
- 同一个密码不能创建多个账户。
- 创建成功后以紧凑面板显示二维码、网址、昵称和密码。
- 填写昵称后左上角显示“昵称的体重日历”；未填写时显示“我的体重日历”。
- 创建或登录后直接进入日历；第一条非零记录会自动成为初始体重。
- 今天及以前的日期都可补记或修改体重。
- 每条记录自动显示相对上一条记录的增减值。
- 记录弹窗支持下滑关闭；修改已有记录时，第一次输入会直接替换旧体重。可记录 0.1 到 999 kg，输入 0 会清空当天记录。
- 保存后日历格、涨跌数字和方向箭头会给出轻量动效；按钮、输入、导航、保存与错误状态使用 UI SFX 的 Zen 音效反馈，音效开关会随账户保存。
- 设置页以岛式分组统一管理五种背景颜色、六种字体、操作音效、体重单位、语言、AI 体重分析、Markdown 数据导出、修改密码、支持作者、使用与隐私说明、退出登录和注销账户。
- 支持公斤、斤、磅和英石，同一份原始数据可按账户偏好转换显示和导出。
- 支持简体中文、香港繁体、台湾繁体、日语、英语和韩语，界面、数据导出和 AI 提示词会一起切换。
- AI 体重分析通过滑块填写身高和估算体脂率，结合近期体重记录生成饮食、运动和睡眠建议，并展示可点击查看数值的近 30 天体重折线图。
- 设置次级页面具有进出场动效，返回时会恢复进入前的设置页滚动位置。
- 日历支持左右滑动切换月份；未解锁日期点击时会晃动并播放提示音。
- 页面固定使用米白与深灰配色的 3D 体重秤图标，不再跟随背景主题换色；Safari 浏览器主题色仍与账户背景同步。
- 手机端月历按整屏布局适配，关闭页面纵向滚动和双击缩放，同时保留设置页的正常滚动。
- 注销需经过两次确认，最后一步输满密码后自动验证。账户会立即停止登录，原密码可重新注册；已注销数据最多保留 30 天并定期清除。
- `/data` 使用同款六位数字键盘登录，包含账户、记录、注销归档和基础访问统计。

## 数据与安全

- 密码不会明文落盘。登录使用 PBKDF2 带盐哈希验证；为满足受保护后台的查看需求，同时保存由 `WCAL_SECRET` 派生密钥加密的副本。
- 旧版账户在首次升级启动时，会利用服务器密钥和有限的六位数字空间一次性补全加密副本。
- 登录态使用随机令牌和 `HttpOnly + SameSite=Strict` Cookie，生产环境增加 `Secure`。
- 用户登录和后台登录在应用层和 Nginx 都有尝试频率限制。
- 访问数据保存原始 IP、由 IP 粗略推测的国家/省市、网络运营信息和访客指纹。位置解析不使用浏览器 GPS，结果仅供访问统计参考。
- 首次遇到一个公网 IP 时，服务器会把该 IP 通过 HTTPS 发送给 IPWhois 查询大致位置；成功结果缓存 30 天，失败结果缓存 1 小时。可用 `WCAL_GEOIP_ENDPOINT` 更换或关闭该第三方服务。
- 数据保存在服务器 SQLite，生产路径为 `/var/lib/wcal/wcal.sqlite3`，不随代码版本切换。
- 只有用户主动点击“生成健康建议”时，身高、估算体脂率及近期体重摘要才会发送给火山方舟；模型密钥只保存在服务器环境变量 `ARK_API_KEY` 中。AI 内容仅作一般生活方式参考，不替代专业医疗建议。
- 四位数字只有一万种组合，六位数字也只有一百万种组合，不适合存放高度敏感信息。不要与银行卡、支付或其他重要密码复用。

## 本地运行

```bash
npm install
npm run build
set -a; source .env; set +a
python3 server.py 8141 dist
```

打开 `http://127.0.0.1:8141`。

开发前端时可同时运行：

```bash
set -a; source .env; set +a
python3 server.py 8141 dist
npm run dev
```

## 测试

```bash
npm test
npm run build
```

## 生产部署

- 正式域名：`https://wcal.mikeywa.site`
- 服务：`wcal.service`
- 应用目录：`/opt/wcal/releases/<release-id>`
- 当前版本：`/opt/wcal/current`
- 数据库：`/var/lib/wcal/wcal.sqlite3`
- 环境变量：`/etc/wcal.env`
- 后端端口：`127.0.0.1:8141`

发布使用版本目录和原子软链切换，保留旧版本用于回滚。

`WCAL_SECRET`、`WCAL_ADMIN_PASSWORD` 和 `ARK_API_KEY` 必须只放在私密环境变量中。不要把真实值提交到 GitHub。参考 [`.env.example`](.env.example)。
